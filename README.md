# ❌⭕ Tic-Tac-Toe Web Application with Multi-Level AI

A clean, responsive, and lightweight Tic-Tac-Toe game built with HTML5, CSS3, and JavaScript. Play against an AI opponent featuring three distinct difficulty modes ranging from completely random moves to an unbeatable algorithm.

---

## 🚀 Features

* **3 AI Difficulty Levels:**
  * **Beginner:** Makes purely random valid moves.
  * **Moderate:** Blends casual play with tactical choices (50% random / 50% optimal).
  * **Hard (Unbeatable):** Employs the recursive **Minimax Algorithm** to calculate every outcome, guaranteeing the AI never loses.
* **Responsive & Dark-Themed UI:** Clean, modern UI styled using CSS Grid for dynamic desktop and mobile responsiveness.
* **Interactive Gameplay:** Instant user input handling with delayed AI response simulation to enhance turn pacing.
* **Zero Dependencies:** Pure Vanilla JS, HTML, and CSS—no external libraries required.
